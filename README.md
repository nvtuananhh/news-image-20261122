A deterministic, standard-library-only Python program that draws a one-page newspaper front page summing up Sunday 22 November 2026: COP31 nears a deal in Antalya, Hong Kong votes in the Election Committee subsector elections, 25 migrants deported from the United States arrive in Liberia as reported that day, plus the day's sport fixtures. The program draws every letter and picture itself in code, with no font files, images, network access, clock reads, or randomness, so repeated runs produce byte-identical output.

## Run it

```sh
python3 main.py
```

This writes the image to `/output/entry.png` (1024x1024 PNG, under 1 MiB).
